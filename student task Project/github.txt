Student Task Management System
CSE471 Group Project

The Student Task Management System is a full-stack web application developed as part of the CSE471 course project.

The system allows students to create an account, securely log in, and manage their academic tasks through a web-based dashboard.

Secure user login

Logout functionality

Database Structure

The application uses two main tables:

Users

Stores registered user information.

Main fields:

id

name

email

password

created_at

Tasks

Stores tasks created by users.

Main fields:

id

user_id

title

description

priority

status

due_date

created_at

Each task is associated with a user through the user_id foreign key.

Installation
1. Install XAMPP

Install XAMPP and start:

MySQL

2. Clone the repository

Place the project inside the XAMPP htdocs directory.

htdocs/student-task-manager/

3. Create the database

Open phpMyAdmin and create/import the database using:

database/database.sql


The database name is:

4. Configure the database

Open:

config/database.php


Update the database host, username and password if necessary.

5. Run the application

Open:

http://localhost/student-task-manager/

Security

The application uses password hashing for storing user passwords and password verification during login.

Database queries use PDO prepared statements to reduce SQL injection risks.

Authentication is managed using PHP sessions, and task operations check the logged-in user's ID to prevent unauthorized access to another user's tasks.

User-generated output is escaped before being displayed in HTML.
